# Public supplementary reproducibility release

This directory publishes the supplemental duration, continuity, and fossil-retention reproducibility package approved for public release on 9 October 2026. The existing baseline repository contents are preserved unchanged.

The 61 original companion files are preserved byte-for-byte. `SHA256SUMS_REVISION.txt` checks the other 60 original files. This release note is additional and is not included in that original manifest.

See `README_REVISION.md` for the analysis protocol, run instructions, interpretation limits, and licensing. Its statements about private delivery and non-publication describe the package's preparation stage before this public release. The `repo/` subdirectory retains the baseline snapshot at commit `e518a95082ba6f2b4df3b3eea433fb6752f35aac` so the supplement can run independently of future baseline changes.
